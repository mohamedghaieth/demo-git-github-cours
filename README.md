# Demo Git & GitHub

Depot de demonstration jetable pour illustrer le manuel Outils Collaboratifs : Git et GitHub.

## Fonctionnalites

- Ajouter un contact
- Afficher les contacts
- Rechercher un contact

## Utilisation

```bash
python app.py
```
